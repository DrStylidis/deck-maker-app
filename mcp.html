MCP server

Deck Maker doubles as an MCP server. Connect it once, and Claude (or Cursor) can build whole decks for you: the assistant writes the content, Deck Maker lays it out in the style you chose, and the result is on-brand every single time.

AI assistants are great at words and hopeless at visual consistency — ask one for slides twice and you get two different-looking decks. Deck Maker fixes the second half. Your styles, extracted from an old PowerPoint, a website, or a plain description, are applied after the writing, by the layout engine rather than the model. The assistant literally can't drift off-brand.

MCP, the Model Context Protocol, is the open standard assistants use to work with apps on your machine. Once connected, yours can extract a style from a .pptx, a .pdf, a URL, or a description · make a deck from notes in any saved style · edit and restyle slides · export PPTX or PDF · and open the result in the app.

Claude Desktop

Open Settings
  1. Open Deck Maker and go to Settings → Connect AI assistants (the button on the right takes you straight there).
  2. Click Connect next to Claude Desktop.
  3. Restart Claude Desktop. The deck-maker tools appear on their own.

Claude Code

Open Settings
  1. Open the same panel: Settings → Connect AI assistants.
  2. Click Copy next to the Claude Code command.
  3. Paste it into a terminal and press return. Done.

Cursor

Open Settings
  1. Open Deck Maker and go to Settings → Connect AI assistants.
  2. Click Connect next to Cursor.
  3. Restart Cursor and the tools are there.

Then just ask

“Take the style from last-year.pptx, turn my notes into a deck in that style, and export a PPTX.” The assistant extracts the style, writes the slides, and Deck Maker does the layout. You can watch the deck appear in the app as it happens.

Deck Maker just needs to be running (on a Mac it even launches itself when the assistant calls). There's nothing extra to install: the connector runs off the app, no Node.js required. The assistant works through a scoped, per-launch token that never leaves your machine: it can create and edit decks and styles, but it can never read your API keys, change settings, or delete anything. Deck authoring runs under your own key, same as in the app. If you don't see Connect AI assistants in Settings, update Deck Maker to the latest release. The Open Settings buttons hand off to the installed app through a deckmaker:// link, so if clicking one does nothing, install (or update) Deck Maker first.
