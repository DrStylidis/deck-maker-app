API keys

Deck Maker authors with your own AI key. Pick one provider below — a single key is enough — and you're about two minutes away from your first deck.

The key means you pay the provider directly, at cost, with nobody in between. It's why the app is free and needs no subscription. Each provider shows a key exactly once when you create it, so copy it right away. If you lose one, just create another.

Anthropic (Claude)

sk-ant-…
  1. Go to console.anthropic.com and sign in (creating an account is free).
  2. Under Billing, add a little credit. $5 is plenty to start.
  3. Open API keys, click Create key, and copy the key.

OpenAI

sk-…
  1. Go to platform.openai.com and sign in.
  2. Under Settings → Billing, add a little credit.
  3. Open API keys, click Create new secret key, and copy the key.

xAI (Grok)

xai-…
  1. Go to console.x.ai and sign in.
  2. Add a little credit under Billing if asked.
  3. Open API keys, create a key, and copy it.

Then paste it into Deck Maker

Open Deck Maker, go to Settings → API keys, paste the key next to your provider, and click Save key. That's the whole setup — authoring now runs under your key.

Keys are stored encrypted in your operating system's keychain (Keychain on macOS, Credential Manager on Windows, the system keyring on Linux) and are sent only to the provider you configured. They never reach us. Prefer no cloud at all? Deck Maker can run against a local model instead.
