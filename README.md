# Deck Maker

**Notes in. Deck out.** Turn Markdown, a PowerPoint, or a PDF into a clean, on-brand, responsive deck — preview on any device, export a PDF or PPTX, all on your machine.

Download the desktop app at **[unintended.me](https://unintended.me)** or below. It's local-first and brings your own API key — no accounts. The only things that leave your machine are calls to the AI provider you configure and anonymous usage statistics (see Privacy).

## What it does

- **Author** — drop Markdown, a `.pptx`, or a `.pdf` and it's mapped onto on-brand layouts automatically.
- **StyleMaker** — drop a PPT/PDF that carries your brand (or point at a website, or just describe it) and reuse that look as a Style across every deck.
- **Export** — one click to a pixel-perfect PDF or PPTX.

## Privacy

Deck Maker sends anonymous usage statistics: app launched, deck created, deck exported, together with the app version, OS, and a random install id. It never sends your deck content, prompts, API keys, or anything that identifies you, and IP addresses are not stored. Turn it off any time in **Settings → Privacy** inside the app.
